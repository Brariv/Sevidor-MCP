# Servidor MCP (Manual de Consulta de Productos)

## Descripción
Este proyecto implementa un servidor que permite a los clientes consultar información sobre productos y sus preguntas frecuentes (FAQ). El servidor expone métodos que los clientes pueden invocar para obtener respuestas a preguntas específicas sobre productos, así como para buscar coincidencias cercanas a preguntas que no existen en la base de datos.

## Instalación
1. Clona este repositorio:
   ```bash
   git clone
    ```
2. Navega al directorio del proyecto:
   ```bash
   cd MCP
   ```
3. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ``` 
4. Corre el servidor:
   ```bash
   python src/Server.py
   ```
